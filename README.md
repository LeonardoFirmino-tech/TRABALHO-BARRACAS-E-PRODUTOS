

| **Requisito**                                               | **explicação**                                                                                                                                                            |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ID do Produto**                                           | Código único que identifica cada produto cadastrado no sistema, evitando duplicidade e facilitando a localização do item.                                                       |
| **ID da Barraca**                                           | Código único utilizado para identificar cada barraca da festa, permitindo relacionar os produtos e as vendas ao local correto.                                                  |
| **Preço**                                                   | Valor de venda de cada produto. Esse valor é utilizado para calcular o total das compras e dos relatórios de vendas.                                                            |
| **Registro do Comprador**                                   | Cadastro ou identificação do comprador para registrar quem realizou a compra, caso seja necessário para controle ou histórico das vendas.                                       |
| **Estoque**                                                 | Quantidade disponível de cada produto. O sistema deve permitir acompanhar a disponibilidade dos itens durante a festa.                                                          |
| **Atualizar automaticamente o estoque após cada venda**     | Sempre que uma venda for concluída, o sistema deve diminuir automaticamente a quantidade do produto no estoque, mantendo as informações atualizadas.                            |
| **Emitir um relatório de vendas por barraca e por produto** | O sistema deve gerar relatórios mostrando a quantidade de vendas e o faturamento de cada barraca e de cada produto, facilitando o controle e a análise dos resultados da festa. |
