# Arraiá Pay 🎪

## 📅 Cronograma do Projeto

| Data | Atividades |
|---|---|
| **03–06/08** | Início do projeto **Arraiá Pay** e seleção dos grupos (barracas e produtos). |
| **10–13/08** | Planejamento do projeto utilizando o **Planner** e finalização dos requisitos funcionais. |
| **17–20/08** | Criação, desenvolvimento e finalização do **MER**, além da finalização do planejamento pelo **Planner**. |
| **24/08** | Criação e desenvolvimento do **DER**. |

## 📌 Etapas do Projeto

### 03–06/08 — Início do Projeto
- Início do projeto **Arraiá Pay**.
- Seleção e organização dos grupos.
- Definição das barracas e dos produtos.

### 10–13/08 — Planejamento
- Planejamento do projeto utilizando o **Planner**.
- Levantamento dos requisitos.
- Finalização dos **requisitos funcionais**.

### 17–20/08 — Modelagem do Banco de Dados
- Criação do **Modelo Entidade-Relacionamento (MER)**.
- Desenvolvimento do MER.
- Finalização e ajustes do MER.
- Finalização do planejamento no **Planner**.

### 24/08 — Desenvolvimento do DER
- Criação do **Diagrama Entidade-Relacionamento (DER)**.
- Desenvolvimento e organização do DER.
- Representação gráfica da estrutura definida no MER.
